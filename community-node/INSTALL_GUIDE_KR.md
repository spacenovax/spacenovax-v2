# Genesis Community Node V1 설치 및 보안 안내

## 이 노드가 하는 일

Genesis Community Node는 SpaceNovaX 중앙 게이트웨이가 배정한 공개 캐시·번역 정적 리소스·서비스 상태 모니터링 작업만 수행합니다. 노드는 Captain ID, 채굴, 보상, 잔액, 지갑, DB, KYC, 관리자 기능에 접근하거나 수정할 수 없습니다.

## 자동 등록 방식

1. SpaceNovaX 앱의 **더보기 → 커뮤니티 노드**에서 1회용 페어링 코드를 발급합니다.
2. 패키지를 내려받아 압축을 풉니다.
3. `SpaceNovaX_Node.exe`를 더블클릭하고 페어링 코드를 입력합니다.
4. 중앙 서버에 자동 등록되며 관리자 수동 승인은 없습니다.
5. 인증정보는 실행 파일 옆 `node-config.json`에 저장되므로 이 파일을 외부에 공유하지 마세요.

Windows 10/11용 독립 실행 파일이므로 Node.js를 별도로 설치할 필요가 없습니다.

## +25% 채굴 속도 보너스

보너스는 노드가 지급하거나 계산하지 않습니다. 중앙 서버가 첫 정상 Heartbeat를 확인하는 즉시 채굴 속도에만 적용합니다.

- 인증된 노드 한 대와 정상 Heartbeat
- 중앙 서버가 배정한 공개 캐시·모니터링 작업 수행
- 변조 파일, 허위 응답, 중복 PC 노드가 없어야 함

노드가 약 2분 동안 오프라인이 되거나 검증에 실패하면 +25%는 자동으로 일시 중지되고, 재연결하면 복구됩니다. 앱 개인 쪽지와 연결된 텔레그램으로 상태 변경을 알립니다. Captain ID·Telegram 계정·PC당 노드는 1대만 허용됩니다. 첫 1,000대에서 신규 등록은 자동 마감됩니다.

## 보안 경계

- 토큰은 읽기·캐시·모니터링 권한만 가지며 15분 후 만료됩니다.
- 노드 비밀값은 중앙 서버에 `scrypt` 해시로만 보관됩니다.
- 앱의 JWT, 관리자 비밀번호, DB 비밀번호, 지갑 키, 보상 서명키를 이 노드에 입력하지 마세요.
- 미니앱과 웹사이트는 노드에 직접 연결하지 않습니다. 중앙 게이트웨이가 검증된 정상 노드만 선택합니다.

## 검증

실행 창에서 `NODE ONLINE`, `HEARTBEAT VERIFIED`, `SHA-256 VERIFIED`, `+25%`가 주기적으로 출력되는지 확인합니다. 앱에서도 **노드가 구동 중입니다 · 채굴 속도 +25%**가 표시되어야 합니다.

`communityNode.js` 및 `tests/community-node-integrity.mjs`는 Node V1의 독립 보안 경계 검증 자료입니다. 실제 앱 연동에는 `agent.mjs`만 사용합니다.
