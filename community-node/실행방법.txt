SPACENOVAX GENESIS COMMUNITY NODE

1. SpaceNovaX 앱 → 더보기 → 커뮤니티 노드에서 1회용 페어링 코드를 발급합니다.
2. SpaceNovaX_Node.exe를 더블클릭합니다.
3. 최초 한 번만 페어링 코드를 입력합니다.
4. NODE ONLINE과 HEARTBEAT VERIFIED가 표시되면 정상 구동 중입니다.
5. 창을 닫으면 노드가 중단되고 약 2분 뒤 +25% 보너스가 일시 중지됩니다.

필수 환경: Windows 10/11, 인터넷 연결 (Node.js 별도 설치 불필요)
노드는 공개 캐시·상태 확인·SHA-256 검증만 수행하며 지갑, 잔액, KYC, 관리자 데이터에 접근하지 않습니다.
