# NOVA Guided Navigation Journey

## 1. 지도 홈
- 현재 위치 중심 지도
- "어디로 갈까요?" 검색 진입
- 빠른 장소: 주차장, 주유소, 식당, 충전소
- 최근 목적지, 저장 장소

## 2. 검색
- 주소, 장소, 지역 이름 자동완성
- 공백 정규화
- 최근 검색과 저장 장소

## 3. 목적지
- 지도 핀과 주변 장소
- 장소 상세 / 목적지 선택
- 출발지 변경, 목적지 변경

## 4. 경로 비교
- 서버가 제공하는 실제 가능한 경로만 표시
- 거리, ETA, 예상 도착 시각
- 안내 시작

## 5. 주행
- 다음 회전, 남은 거리, ETA, 현재 속도
- GPS 재검색, 목적지 변경, 종료
- 사용자 클릭 뒤 음성 및 자막 안내

Safety: road signs, local regulations, and the driver's judgment are always primary.
